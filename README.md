## 🚀 How to Run Locally

1. **Direct Open**: Double-click `index.html` to view in any browser.
2. **VS Code Live Server**: Open in VS Code, right-click `index.html` and choose **"Open with Live Server"**.

---

## 🌐 How to Host / Update on GitHub Pages

1. Commit and push changes to your `jessica-portofolio` repository on GitHub.
2. Go to **Settings -> Pages** in your repository.
3. Ensure source is set to **Deploy from a branch (`main` / `/root`)**.
4. Your website is live at `https://jessica244.github.io/jessica-portofolio/`.
