# 🎬 Movie App

A responsive, modern web application built with **React.js and REST APIs** for browsing, searching, and exploring movies.

---

## ✨ Features

- 🔍 **Search & Discover**: Find movies by title, genre, or popularity.
- ⚡ **Real-time API Integration**: Fetches dynamic movie data, ratings, posters, and overviews.
- 📱 **Responsive UI**: Optimized for mobile, tablet, and desktop screens using modern CSS Grid and Flexbox.
- 🧩 **Component Architecture**: Built with reusable React functional components and state hooks.

---

## 🛠️ Tech Stack

- **Framework / Library**: React.js
- **Build Tool**: Vite / Create React App
- **Language**: JavaScript (ES6+)
- **Styling**: Modern CSS3 / Flexbox & CSS Grid
- **API**: TMDB / OMDb Movie API

---

## 🚀 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/jessica244/movie-app.git
   cd movie-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```
