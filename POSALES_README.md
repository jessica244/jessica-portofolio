# 🛒 POSales — Point of Sale System

A Point of Sale (POS) desktop application built with **C#** to manage sales, products, inventory, and customer transactions efficiently.

---

## ✨ Features

- 📦 **Inventory Management**: Add, update, and track product stock levels.
- 💳 **Sales & Checkout**: Process billing, calculate totals, discounts, and print receipts.
- 📊 **Transaction History**: View sales history and daily summary reports.
- 🔒 **User Management**: Role-based access for admins and cashiers.

---

## 🛠️ Tech Stack

- **Language**: C#
- **Platform**: .NET Framework / Windows Forms / WPF
- **Database**: SQL Server / SQLite / LocalDB
- **Paradigm**: Object-Oriented Programming (OOP)
