# ⛵ Al-Folk App — Down Syndrome Support Platform

> 🏆 **1st Place Winner** at the Delta Universities Environmental Competition (المؤتمر/الملتقى البيئي لجامعات الدلتا) — Awarded **10,000 EGP**.

Al-Folk App is a specialized web application developed as a **Graduation Project** by Computer Science students at Tanta University. It aims to support children with Down Syndrome and empower their families through cognitive skill-building games and developmental tracking.

---

## ✨ Features

- 🎮 **Cognitive & Motor Skill Games**: Interactive, custom-built games designed specifically for children with Down Syndrome.
- 📈 **Progress Tracking Portal**: Allows parents and caregivers to monitor developmental milestones.
- 📱 **Fully Responsive Interface**: Accessible across desktop computers, tablets, and smartphones.
- 🎨 **Accessibility-First Design**: Thoughtful colors, typography, and UI elements tailored for ease of use.

---

## 🛠️ Tech Stack

- **Front-End**: HTML5, CSS3, JavaScript (ES6+)
- **Layout**: Flexbox & CSS Grid
- **Design & Prototyping**: Figma
